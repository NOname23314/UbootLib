## 3. 过程中的技术要点（供后续开发参考）

1. **首次启动需数分钟**：Cpp2IL 解析 + 89 个 Interop 程序集生成约 90 秒（`BepInEx/interop/` 51 MB）。之后启动走缓存（`BepInEx/cache/chainloader_typeloader.dat`），秒级完成。
2. **插件工程必须引用 `Il2Cppmscorlib.dll`**：否则 `UnityEngine.Object` 等基类型无法解析，报 `CS0012`。需引用 `Il2Cppmscorlib` / `Il2CppSystem` / `Il2CppSystem.Core` + 目标 Unity 模块（见 `src/HelloWolfpack/HelloWolfpack.csproj`）。
3. **优先用强类型解析补丁目标**：`AccessTools.Method("NS.Type:Method")` 会触发全程序集类型扫描，产生 `ReflectionTypeLoadException` 警告（本次已改为 `AccessTools.Method(typeof(T), "Method")`，日志归零）。
4. **`W_NetworkManager` 在 Interop 程序集中方法数为 359**（含继承属性访问器），`dump.cs` 中的 180 是声明方法数——两者都属正常，统计口径不同。
5. **日志文件名是 `LogOutput.log`**，不是旧版文档常写的 `LogOutput.txt`。
