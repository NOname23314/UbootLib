## 1. 交付内容

| 文件 | 作用 |
|---|---|
| `src/WolfpackModKit/Hud.cs` | uGUI 叠加层：Canvas + CanvasScaler + Text 标签管理，按场景重建 |
| `src/WolfpackModKit/Il2Cpp.cs` | 类型解析辅助（`Il2Cpp.FindType`），避免全程序集扫描 |
| `ModContext.Hud` | Mod 通过 `Context.Hud.AddLabel/SetText/Get/Remove` 操作叠加层 |
| `src/samples/SampleHud/SamplePlugin.cs` | 参考 Mod：创建标签并在每 30 帧刷新文本 |

### 架构要点

- **重建策略**：Canvas 属于当前场景对象，场景切换即被销毁。框架在场景钩子里打 `MarkForRebuild`，
  由帧泵在下一帧调用 `Hud.Tick()` 重建 —— 避免在 `OnSceneLoaded` 回调内直接建对象（P2 的崩溃教训）。
- **坐标体系**：`ScreenSpaceOverlay` + `ScaleWithScreenSize`（参考分辨率 1920×1080，`matchWidthOrHeight=0.5`），
  标签以左上角为锚点（`anchor(0,1)` / `pivot(0,1)`），位置写屏幕坐标即可，自动适配 2560×1440。
- **层级**：`sortingOrder = short.MaxValue`，保证叠加在游戏 UI 之上。
- **字体**：优先内置 `Arial`，失败再尝试系统中文字体，最后记录错误日志（不会静默失败）。

## 3. 踩坑记录

1. **IMGUI 彻底不可用**：`OnGUI` 依赖 MonoBehaviour 回调，而 ClassInjector 注入在本作会崩（见 P2），
   因此所有 HUD 必须走 uGUI。
2. **字体是第一个坑**：最初优先调用 `Font.CreateDynamicFontFromOSFont("Microsoft YaHei")`，
   返回非 null 但文本完全不渲染（Canvas 与标签都正常，只是看不见）。
   改为**优先内置 Arial** 后立刻正常 —— 这类"对象都正常但没画面"的问题，优先怀疑字体。
3. **部署时文件占用**：游戏进程未完全退出时 `Copy-Item` 会失败（dll 被占用），
   导致"改了代码但跑的是旧版本"。部署脚本需 `Wait-Process` 等待退出，`tools/deploy_plugin.ps1` 已可用于插件目录；
   Mod 目录的部署脚本待补。

## 4. 已知限制

- **中文渲染**：内置 Arial 不含 CJK 字形，HUD 目前只保证英文/数字。
  中文 HUD 需提供 TMP 字体资产或系统中文字体裁剪，列入 P4。
- **交互**：当前不支持点击（未挂 `GraphicRaycaster` 与 `EventSystem`），仅做只读展示。
- **布局**：仅左上角锚点 + 绝对坐标；后续需要锚点枚举与自动换行。

## 5. 配置热重载（本轮新增）

- `ModContext.GetConfig/SetConfig` 以 `Mods/<Id>/config/<key>.json` 落盘。
- `ModLoader` 为每个已加载 Mod 建立 `FileSystemWatcher`，变更事件入队，
  由帧泵在主线程出队并依次调用 `IMod.OnConfigChanged(key)` 与 `ModContext.ConfigChanged`——
  保证回调永远在 Unity 主线程执行。
- **实测**：游戏运行中把 `config/showHud.json` 改为 `false` → `hot-reloaded showHud=False`（HUD 隐藏）；
  改回 `true` → HUD 恢复。日志 0 错误。

**踩坑**：`FileSystemWatcher` 若只保存在局部变量，会被 GC 回收导致事件静默失效
（第一次实测完全无反应）；必须用静态列表持有引用。
